Confirmation dialog

One dialog for every approve / cancel-approval action in the portals. It is not a per-page component: a page supplies a title, a body, an OK label and a callback; the surface, buttons and behaviour never change. Do not build a new one — reuse this.

Live demo

Open one, then Cancel or confirm. Esc and a click on the backdrop also dismiss it.

Anatomy

Cancel approval?
Swing Tag will be sent back to Pending Approval and will need to be re-approved.

Surface .modal-overlay > .modal-box · title 15px / 600 · body 12.5px in --tw2 · footer right-aligned: secondary .btn-g “Cancel” + primary .btn-p with the action label. Overlay id is ra-confirm-modal (Retailer Admin) / sa-confirm-modal (Super Admin).

Markup

<div class="modal-overlay" id="ra-confirm-modal">
  <div class="modal-box">
    <div style="font-size:15px;font-weight:600;margin-bottom:8px" id="ra-confirm-title">Confirm</div>
    <div style="font-size:12.5px;color:var(--tw2);margin-bottom:18px;line-height:1.5" id="ra-confirm-body">Are you sure?</div>
    <div style="display:flex;justify-content:flex-end;gap:8px">
      <button class="btn-g" onclick="raConfirmCancel()">Cancel</button>
      <button class="btn-p" id="ra-confirm-ok" onclick="raConfirmOk()">Approve</button>
    </div>
  </div>
</div>

// usage
raShowConfirm('Cancel approval?', 'Swing Tag will be sent back…', 'Cancel approval', function () { /* do it */ });
