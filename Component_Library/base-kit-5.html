GreenStreets design system

Supplier Portal — base components

Every primitive the Supplier Portal is built from, one per frame, drawn by the portal's own production stylesheets. Where a component has more than one state, each state is drawn beside the default from the real declarations. This sheet is the drawing; code and documentation live in the component library.

—

The surface everything sits on

  • Canvas#070f1cthe page behind everything
  • Accent#4ebb81brand green - primary actions, active nav, focus
  • Accent light#8fe3b6gradient top end, active indicator
  • Info#5b9cf6links and informational status
  • Warning#f5a623attention, expiring, low confidence
  • Danger#e0605adestructive actions and failures
Type
Inter 300-700. Body 13px, labels 11px uppercase, page title 21px.
Corner radius
10px controls, 13px cards, 18px panels.
Spacing
A 7-step scale: 4px, 8px, 12px, 16px, 20px, 24px, 32px.
Control height
Buttons 42px. Fields 10px/12px padding at 13px, so ~39px.
Ink
Full white for primary text, rgba(255,255,255,.74) for secondary, rgba(255,255,255,.62) for muted.
Hairline
1px rgba(148,180,230,.16); rgba(148,180,230,.26) where a border needs to read as an edge.
Focus
A 2px ring in the accent, drawn on at the control's own radius. It follows the accent, so re-theming moves it.
Surfaces
Cards are a near-transparent white wash over the page, with a blur behind them - so the background gradient reads through every panel.
